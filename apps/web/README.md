# apps/web — Docite Frontend

Vite + React 19 + TypeScript + Tailwind v4 single-page application.

**Belongs here:** UI components, feature modules, routing, static assets, API type definitions and network calls.
**Must NOT go here:** Business logic, database access, secrets, server-side code, or any Python.

## Dev
```powershell
cd apps/web
npm install
npm run dev        # http://localhost:5173
npm run build      # production bundle → dist/
npm run lint       # ESLint
```
